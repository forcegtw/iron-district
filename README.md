# Iron District

A round-based tactical FPS built with three.js for the [make.fun](https://make.fun) bounty *Make the best three.js tactical FPS* ([threejs-fps-01](https://make.fun/c/threejs-fps-01)).

Buy phase → live round → plant/defuse device → payout economy. 3 enemy bots with routes, FOV, reaction delay and burst fire; 4 weapons, grenades, full HUD.

Deterministic screenshot mode: `?shot=start|play|end&seed=7`.
