Iron District: a round-based tactical FPS built with three.js by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

Buy phase → live round → plant/defuse device → payout economy. 3 enemy bots with routes, FOV, reaction delay and burst fire; 4 weapons, grenades, full HUD, killcam, stats and sweep radar.

Deterministic screenshot mode: `?shot=start|play|end&seed=7`.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in desktop Chrome.
